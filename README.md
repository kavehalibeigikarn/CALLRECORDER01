# اپلیکیشن ضبط تماس — CallRecorder

اپ نیتیو اندروید (Kotlin + Jetpack Compose) برای ضبط خودکار مکالمات تلفنی.
طراحی‌شده برای **موتورولا اِج ۵۰ پرو / اندروید ۱۶**، ولی روی هر گوشی اندروید ۸ به بالا کار می‌کند.

---

## چطور کار می‌کند

اپ هنگام برقراری تماس به‌طور خودکار شروع به ضبط می‌کند و با پایان تماس ذخیره می‌کند.
دو مسیر ضبط دارد که خودکار انتخاب می‌شوند:

| حالت | شرط | کیفیت |
|------|-----|-------|
| **ROOT** | گوشی روت باشد | هر دو طرف، مستقیم و تمیز (منبع `VOICE_CALL`) |
| **MIC** | بدون روت (پیش‌فرض) | صدای شما تمیز؛ صدای طرف مقابل فقط با **بلندگوی روشن** |

> مهم: روی اندروید ۱۰ به بعد، منبع `VOICE_CALL` برای اپ‌های غیرسیستمی مسدود است.
> بدون روت، تنها راه ممکن میکروفون است و برای شنیدن طرف مقابل باید بلندگو (Speaker) روشن باشد.

## روش ۱ (توصیه‌شده): ساخت APK با گیت‌هاب — بدون نیاز به کامپیوتر

گیت‌هاب خودش پروژه را در فضای ابری کامپایل می‌کند و APK آماده را تحویل می‌دهد.

۱. در [github.com](https://github.com) یک حساب بسازید (رایگان).
۲. یک ریپازیتوری جدید بسازید: دکمهٔ **New** → یک نام مثل `call-recorder` → **Create repository**.
۳. محتوای این پوشه را آپلود کنید:
   - در صفحهٔ ریپو روی **Add file → Upload files** بزنید،
   - **همهٔ فایل‌ها و پوشه‌ها** را (از حالت zip خارج‌شده) بکشید و رها کنید،
   - پایین صفحه **Commit changes**.
۴. به تب **Actions** بروید. یک اجرای «ساخت APK» به‌طور خودکار شروع می‌شود (چند دقیقه طول می‌کشد).
   - اگر خودکار شروع نشد: از منوی کنار، «ساخت APK» را انتخاب و **Run workflow** بزنید.
۵. وقتی تیک سبز خورد، روی همان اجرا کلیک کنید. پایین صفحه بخش **Artifacts** فایل
   `CallRecorder-debug-apk` هست — دانلودش کنید.
۶. فایل را از zip خارج کنید (`app-debug.apk`) و روی گوشی نصب کنید.
   - موقع نصب، اگر پیام «Install from unknown sources» آمد، اجازه بدهید.

> نکته: هر بار فایل‌ها را در ریپو عوض کنید، APK جدید خودکار ساخته می‌شود.

---

## روش ۲: ساخت با Android Studio (اگر کامپیوتر دارید)

۱. پوشه را در **Android Studio** (نسخهٔ Koala یا جدیدتر) باز کنید: `File → Open`.
۲. صبر کنید Gradle Sync تمام شود.
۳. گوشی را با USB Debugging وصل کنید و روی **Run ▶** بزنید.

یا از خط فرمان:

```bash
cd CallRecorder
./gradlew assembleDebug
# خروجی: app/build/outputs/apk/debug/app-debug.apk
```

## مجوزهایی که باید بدهید

هنگام اولین اجرا این مجوزها را تأیید کنید:
- **میکروفون** (ضبط صدا)
- **تلفن** (تشخیص شروع/پایان تماس)
- **مخاطبین** (نمایش نام به‌جای شماره)
- **اعلان** (اعلان ضبط در حال اجرا)

سپس در تنظیمات گوشی، برای اپ **اجازهٔ اجرای پس‌زمینه بدون محدودیت** (Battery → Unrestricted) را بدهید تا سرویس ضبط توسط سیستم بسته نشود.

## فعال‌کردن مسیر روت (اختیاری، برای ضبط تمیز هر دو طرف)

اِج ۵۰ پرو باز کردن رسمی بوت‌لودر را پشتیبانی می‌کند (نسخهٔ جهانی، نه قفل‌شده به اپراتور):

۱. کد باز کردن قفل را از سایت موتورولا بگیرید.
۲. بوت‌لودر را باز کنید (توجه: کل گوشی پاک می‌شود).
۳. **Magisk** را نصب کنید.
۴. در Magisk به این اپ دسترسی **Grant** بدهید.

بعد از روت، اپ خودکار تشخیص می‌دهد و به حالت ROOT سوئیچ می‌کند. برچسب بالای صفحه از «میکروفون» به «روت: فعال» تغییر می‌کند.
